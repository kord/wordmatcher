# Word Matcher

The plan is to make this a simple little game matching
english and chinese words.

Trashy provisional logo from [Brandcrowd](https://www.brandcrowd.com)

### Libraries
[Pinyin](https://github.com/zh-lx/pinyin-pro)

[Converting Simplified to Traditional](https://github.com/nk2028/opencc-js)

[Command line util for simplified/traditional conversion](https://github.com/BYVoid/OpenCC)

[Another, seemingly less Taiwanized tool for the same](https://github.com/berniey/hanziconv)
